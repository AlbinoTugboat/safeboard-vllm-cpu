# Дополнительные измерения CPU, 21 октября 2026 года

По решению пользователя эксперименты остановлены. Рабочая конфигурация сохранена: Qwen2.5-1.5B-Instruct BF16, исходный образ `safeboard-vllm:0.32.0`, OMP/MKL 8, привязка `nobind`. Временные переопределения Deployment и задание загрузки AWQ удалены. Основные Dockerfile, зависимости, манифест модели и настройки инференса не менялись.

`baseline-256.json`: четыре последовательных запроса с коротким входом, каждый с выходом 256 токенов. Средний TTFT — 0,230 с, полная задержка — 24,595 с, суммарная скорость серии — 10,409 выходного токена/с. Оценка скорости после первого текстового фрагмента — 10,466 токена/с. Последняя величина рассчитана по интервалам SSE на клиенте и включает транспортные накладные расходы; это не внутренняя метрика движка.

`baseline-8.json` и остальные файлы содержат отдельные пробы на 128 выходных токенах: по четыре запроса на сценарий, одинаковые входы и уникальная соль кэша. Привязка потоков к физическим ядрам давала около 14,4–14,8 токена/с в одном коротком потоке, но в рабочую конфигурацию не перенесена. В сопоставимой пробе AMD Zen backend не показал существенного выигрыша. Это небольшие последовательные локальные серии, без рандомизации порядка; они не доказывают оптимальность настройки. В каждом отчёте сохранены фактические Pod, образ, настройки, привязка endpoint по audit log и исходные измерения. Эти Pod относятся ко времени измерений, а не к текущему развёртыванию.

`baseline-256-quality.json` — отдельная проверка на 12 синтетических заданиях: 9 строгих совпадений, одна арифметическая ошибка и два нарушения требования вернуть JSON без Markdown. Это проверка отдельных примеров, а не оценка общей точности модели.

`model-awq.lock.json` описывает только пробного кандидата. Его загрузка завершилась ошибкой; AWQ не подключалась к сервису и не проходила измерений скорости или сравнения качества. Экспериментальный образ Zen также не используется. `legacy-32.json` сохраняет исходный тест с выходом 32 токена; основной отчёт `../benchmark.json` оставлен без изменений.

Инструменты для воспроизведения дополнительных измерений — `scripts/benchmark_decode.py` и `scripts/check_model_quality.py`. Автоматического продолжения экспериментов нет.
